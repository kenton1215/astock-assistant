# A股短线交易体系（量化落地版）

> 由资深短线作手框架进一步完善与量化。**本体系仅为交易方法论研究，不构成投资建议，不保证盈利。股市有风险，入市需谨慎。**

---

## 〇、一句话总纲

> **在情绪上升期，用固定模式，买最强板块的最强个股；错了小亏走，对了让利润奔跑。**

短线赚的是情绪、资金、趋势、惯性的钱。核心不是"每次都对"，而是在可重复的模式下：**胜率 × 赔率 × 频率 × 仓位** 的组合优势。

---

## 一、情绪周期模型（决定总仓位的第一性变量）

情绪周期是短线的"天气"，所有操作先看天气。用五个可量化指标定位周期：

| 阶段 | 涨停家数 | 炸板率 | 连板高度 | 昨日涨停今日表现 | 总仓位 |
|---|---|---|---|---|---|
| **冰点** | <40家 | >35% | ≤2板 | 闷杀（均值为负） | 试错仓 ≤30% |
| **启动** | 50~80家 | 20~30% | 3~4板 | 回暖（均值为正） | 50~60% |
| **发酵** | 80~120家 | <25% | 5板+，梯队完整 | 溢价（均值>+2%） | 70~80% |
| **高潮** | >120家且持续，高位股集体加速 | 低但次日易骤变 | 龙头加速一字/秒板 | 极高溢价 | 逐步兑现，只卖不追 |
| **退潮** | 炸板率骤升>40%、龙头断板、跌停增多 | — | 高度骤降 | 闷杀 | ≤20% 或空仓 |

**周期转换信号（必须提前预警，而不是事后确认）：**
- 发酵→高潮：龙头从"换手板"变"加速板/一字板"；跟风补涨股批量涨停（低位股集体躁动）。
- 高潮→退潮：最高标炸板、炸板率单日翻倍、跌停家数突然增加、主线板块集体长上影。
- 冰点→启动：出现新的"大题材+政策强催化"，首板批量出现且次日有溢价。

## 二、选股五维指标体系（缺一不可）

### 1. 趋势维（位置决定赔率）
- ✅ 多头排列：现价 > MA5 > MA10 > MA20
- ✅ 平台突破：横盘 ≥10 日后放量突破平台高点/20日新高
- ✅ 强势整理：突破后回踩 MA5/MA10 不破
- ❌ 一票否决：均线空头排列、下降通道、连续阴跌、缩量无波动

### 2. 量能维（资金验证）
- 成交额 ≥ 2亿（流动性底线）；流通市值 20~500亿（弹性与安全的平衡）
- 换手率 3%~25%（<3% 无人气，>25% 换手过热、分歧巨大；涨停股可放宽到40%）
- 量比 ≥ 1.2（突破模式要求 ≥1.5）
- 主力净流入为正（净流入占比越大越好）

### 3. 板块维（板块效应是短线的第一选股原则）
- 个股所属板块当日涨幅排名前 30%（前 10 名更佳）
- 板块内有涨停梯队：龙头（最高板）+ 中军（大成交额）+ 跟风（首板/二板）
- 板块主力资金净流入为正
- 优先做板块启动初期的龙头，其次最强的一两个补涨，不做杂毛跟风

### 4. 股性维（涨停基因）
- 近 20 日出现过涨停（有资金记忆）
- 当前连板数、历史最大连板高度（衡量弹性）
- 龙虎榜偏好：游资接力好、机构砸盘坏（看次日承接，不迷信席位）

### 5. 情绪维（催化与共振）
- 催化：政策重磅/行业涨价/业绩超预期/重大合同/并购重组/海外映射
- **事件必须与市场情绪共振**：冰点期的利好易高开低走，发酵期的普通消息也能涨停
- 逻辑要能一句话说清，讲不清的不做

## 三、五种买点模式（条件化扣扳机）

| 模式 | 触发条件（全部满足才买） | 买点 | 止损 | 止盈 |
|---|---|---|---|---|
| **突破买点** | 放量(量比≥1.5)突破20日新高/平台 + 板块同步走强 + 分时回踩不破均价线 + 大盘不急跌 | 突破瞬间 / 回踩确认 / 尾盘确认，突破价±1% | 跌破突破位 或 -5%（先到先走） | 前高、整数关、情绪高潮 |
| **回踩买点** | 上升趋势 + 缩量回踩MA5/MA10 + 抛压不大 + 再次放量 | 均线企稳时低吸，或再放量突破分时高点 | 均线下 3% | 前高、加速兑现 |
| **弱转强买点** | 昨涨停/大涨 → 今日低开(不深杀) → 快速拉回 → 上穿分时均价线放量 + 板块没崩 | 分时弱转强确认时 | 今日最低点 | 次日看强弱，不强走 |
| **龙头反包买点** | 龙头首阴/长上影 + 次日不破关键支撑 + 快速反包 + 板块未退潮 | 反包过前日高点 或 分时放量拉升时 | 前日低点 | 加速后首阴兑现 |
| **连板低吸/回封** | 只做主线板块龙头 + 分歧不破位（竞价低开不超-5%） | 分歧低吸 或 回封打板 | -5% 或破位 | 断板/放巨量滞涨必走 |

**买点六条共同要求**：有板块效应、有成交量配合、分时强势、大盘不极端恶劣、符合自己的模式、提前设好止损。

## 四、卖点纪律（会卖的是师傅）

### 止损（第一原则，机械执行）
1. 跌破买入逻辑 → 走
2. 跌破关键支撑（MA5/MA10/突破位）→ 走
3. 亏损达到 -5%（或模式预设比例）→ 走，**绝不把短线做成中线、中线做成股东**
4. 板块退潮 → 走
5. 大盘急跌/系统性风险 → 减仓或走

### 止盈（让利润奔跑 ≠ 死拿）
1. 目标位止盈：前高、整数关、压力位
2. 情绪高潮止盈：板块集体涨停、龙头加速、市场极度亢奋
3. 分时走弱止盈：冲高回落、跌破分时均价线、放量滞涨
4. 时间止盈：买入后 1~3 天不涨 → 走（资金效率）
5. 换股止盈：出现更强目标 → 切换

### 必须走的信号（出现即卖，不犹豫）
- 龙头炸板、板块跟风大跌
- 高位放巨量滞涨
- 连续加速后出现长上影
- 跌破 5 日线且反抽无力
- 利好后高开低走
- 市场情绪从亢奋转冰点

## 五、仓位与风控（生命线）

| 规则 | 标准 |
|---|---|
| 单票仓位 | ≤ 总资金 20%~30%（极高确定性才可上浮） |
| 同时持股 | 2~4 只，且方向不能完全一样（同板块 ≤2 只） |
| 单笔亏损 | ≤ 总资金 1%~2%（仓位 × 止损幅度联动计算） |
| 连续亏损 | 连亏 3 笔 → 强制休息一天，复盘原因 |
| 回撤控制 | 回撤 10% → 仓位减半；回撤 20% → 空仓复盘 |
| 总仓位 | 随情绪周期调节（见情绪周期表） |

**仓位公式**：单票仓位 = min(20%, 总资金×2% ÷ 止损幅度)。例：止损-5%，单笔风险2% → 单票仓位 = 2%÷5% = 40% → 按 20% 上限执行。

## 六、每日交易流程

**盘前（08:30~09:25）**
1. 隔夜外盘、政策、消息面（Tavily 检索辅助）
2. 昨日复盘结论：涨停梯队、炸板率、主线板块、龙头走势
3. 选出今日观察板块与候选名单，写明触发价、买入价、止损价
4. 9:25 竞价观察：候选股高开幅度、昨日涨停股溢价、大盘竞价方向

**盘中（09:30~11:30 / 13:00~15:00）**
1. 看大盘：指数、涨跌家数、情绪温度
2. 看板块：龙头是否封稳、跟风是否跟上、炸板是否增多
3. 看个股：分时、量能、承接；只执行计划，不临时起意
4. 记录：为什么买、为什么卖（复盘素材）

**盘后（15:00 后）**
1. 复盘涨停/跌停/炸板率、连板梯队、主线板块
2. 复盘自己的每一笔交易：对在哪、错在哪、模式是否变形
3. 更新明日计划（候选、触发条件、持仓处置预案）

## 七、本助手如何落地这套体系

| 体系环节 | 系统落地 |
|---|---|
| 情绪周期 | 实时统计涨停/跌停/炸板率/连板高度/昨涨停表现 → 大模型定位周期与总仓位 |
| 板块效应 | 行业/概念板块涨幅榜 + 板块内涨停家数 + 主力净流入 → 锁定主线 |
| 五维选股 | 规则初筛（量能/市值/换手/量比/趋势/ST/一字板一票否决）→ 多因子打分 → Top50 送入大模型 |
| 五种买点 | 候选按模式分桶（突破/回踩/连板涨停/趋势跟随）→ 大模型给出建议买入区间/止损/目标 |
| 卖点纪律 | 持仓逐只核对：盈亏、均线、板块、量价 → 给出 卖出/减仓/持有 结论与参考价 |
| 检查清单 | 25 项检查清单嵌入提示词，大模型必须逐项给出结论（见《短线交易检查清单》） |

## 八、最后的核心总结

1. 只做强势股 2. 只做模式内 3. 买点条件化 4. 卖点纪律化 5. 仓位可控化 6. 情绪周期化 7. 复盘持续化

短线成功不是靠预测，而是靠**纪律**：在情绪上升期，用固定模式，买最强板块的最强个股，错了小亏走，对了让利润奔跑。
