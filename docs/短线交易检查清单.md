# 短线交易检查清单（盘前 / 盘中 / 盘后）

> 每天 4 个时段由智能体自动执行本清单核对，逐项给出结论写入报告。**清单目的是"过滤"而非"寻找"：任何一项不通过，宁可不做。**

---

## 一、盘前检查清单（08:30 ~ 09:25）

### A. 大局观（先看天气）
- [ ] A1 隔夜外盘：美股三大指数、中概股、A50期指涨跌如何？
- [ ] A2 政策消息：有无重磅政策/监管表态/行业利好？（Tavily 检索）
- [ ] A3 今日日程：有无重大数据发布、限售解禁、会议事件？
- [ ] A4 昨日大盘：指数位置、两市成交额（放大还是萎缩）？
- [ ] A5 昨日情绪：涨停/跌停/炸板率、连板高度、涨停梯队如何？
- [ ] A6 昨日主线：哪个板块最强？龙头是谁？今日是否有延续逻辑？

### B. 候选股池（提前选好，盘中只执行）
- [ ] B7 今日观察板块 ≤3 个（宁少勿多）
- [ ] B8 每板块选定：龙头、中军、最强补涨各 1~2 只
- [ ] B9 每只候选写明：买入模式、触发价、买入区间、止损价、目标价、仓位
- [ ] B10 候选逻辑能否一句话说清？（说不清 → 放弃）

### C. 仓位与风控（盘前定死）
- [ ] C11 当前情绪周期？对应的总仓位上限是多少？
- [ ] C12 现有持仓的今日预案：什么价位止损？什么信号止盈？
- [ ] C13 是否处于连亏状态？（连亏 3 笔 → 今日只观察不下单）
- [ ] C14 可用资金多少？单票仓位计算好了吗？

### D. 竞价观察（09:15 ~ 09:25）
- [ ] D15 昨日涨停股竞价：普遍高开（情绪好）还是低开闷杀（情绪差）？
- [ ] D16 候选股竞价：高开幅度是否在合理区间（-3% ~ +5% 可操作）？
- [ ] D17 大盘竞价方向：指数高开/低开？涨停/跌停家数初值？
- [ ] D18 竞价后是否调整预案？（只降预期，不临时起意追高）

---

## 二、盘中检查清单（09:30 ~ 11:30 / 13:00 ~ 15:00）

### E. 大盘监控（每 30 分钟核对一次）
- [ ] E1 指数：是否出现急跌/跳水？（急跌 → 暂停一切买入）
- [ ] E2 涨跌家数：上涨家数是否持续大于下跌家数？
- [ ] E3 涨停家数 vs 昨日同时段：情绪在升温还是降温？
- [ ] E4 炸板率：是否在快速上升？（>40% → 警惕退潮）

### F. 板块监控
- [ ] F5 主线板块：龙头是否封稳？封单是否稳定？
- [ ] F6 跟风股：跟风是否跟上？（主线只有龙头独舞 → 强度存疑）
- [ ] F7 板块资金：主力资金是流入还是流出？
- [ ] F8 是否有新板块卡位？（新主线出现 → 评估是否切换）

### G. 买入执行（扣扳机前逐项确认）
- [ ] G9 这是计划内的股票吗？（计划外 → 不做）
- [ ] G10 买入模式触发条件全部成立了吗？（见体系五模式表）
- [ ] G11 分时图：是否强势（在均价线上方、回踩不破）？
- [ ] G12 成交量：是否放量配合？
- [ ] G13 止损价挂在系统里了吗？（先挂止损，再下单）
- [ ] G14 仓位符合单票上限与单笔风险限额吗？

### H. 持仓监控
- [ ] H15 持仓股是否跌破买入逻辑/关键均线？
- [ ] H16 持仓股所属板块是否退潮？
- [ ] H17 持仓股是否出现：放量滞涨、高位长上影、分时走弱？
- [ ] H18 到目标位了吗？到止损位了吗？（到价执行，不商量）

---

## 三、盘后检查清单（15:00 收盘后）

### I. 市场复盘
- [ ] I1 今日情绪周期定性：处于五阶段哪一阶段？依据是什么？
- [ ] I2 涨停/跌停/炸板率数据：与昨日对比，情绪转强还是转弱？
- [ ] I3 连板梯队：最高几板？2/3/4/5板各几家？（梯队断层 = 强度不足）
- [ ] I4 今日主线板块：启动第一天还是连续大涨？（连续大涨 → 注意高潮风险）
- [ ] I5 昨日涨停今日表现：平均涨幅为正（有溢价）还是为负（闷杀）？

### J. 个股复盘
- [ ] J6 今日买入候选回顾：触发买点了吗？表现如何？
- [ ] J7 龙虎榜（盘后晚间更新）：候选/持仓有无游资接力或机构砸盘？
- [ ] J8 涨停股共性：今日涨停股集中在哪些板块/什么逻辑？

### K. 交易自检（最重要的部分）
- [ ] K9 今天做对了吗：买卖是否符合模式？有无临时起意？
- [ ] K10 今天做错了吗：错在哪一环？（选股/买点/卖点/仓位/情绪）
- [ ] K11 止损执行了吗？（没执行 → 明天第一件事补上）
- [ ] K12 连亏记录：目前连亏几笔？是否触发强制休息？

### L. 明日计划
- [ ] L13 明日情绪预判：大概率延续/分歧/退潮？对应总仓位？
- [ ] L14 明日观察板块与候选：每只写明触发条件与价格
- [ ] L15 持仓明日预案：止损位/止盈位/减仓条件
- [ ] L16 明日风险点：解禁、公告、外盘事件？

---

## 四、每日自检八问（收盘后必答）

1. 我今天买的是最强板块的最强股吗？
2. 我买入时，模式触发条件全部成立了吗？
3. 我的止损价提前设定并执行了吗？
4. 我的仓位符合情绪周期和风控上限吗？
5. 我今天有没有做计划外的交易？
6. 我今天卖出的依据是纪律还是情绪？
7. 今天的操作若重来一遍，我会怎么改？
8. 当前连续盈亏状态如何？明天应该进攻还是防守？

> **纪律是唯一的风控。清单每一项都必须有结论：通过、不通过、不适用。**
